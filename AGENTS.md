# Источник редизайна и ограничения

## Git — только по прямой просьбе пользователя

По последнему указанию пользователя **коммиты и push выполнять только по его прямой просьбе**. Обычная работа над прототипом, проверки и предпросмотр — локально. Не запускать Sites/Git-помощники, которые автоматически создают коммит или выполняют push, без соответствующей просьбы. Прежнее разрешение на публикацию не распространяется автоматически на будущие изменения. Если запрошен только коммит, push не выполнять.

## Старая система — строго только просмотр

Дополнительный основной источник с 6 ноября 2026 года: https://my-dev.astron.imbateam.tech/. Изучать все доступные страницы текущей роли, не изменяя данные. Вход выполняет пользователь. Не вводить и не отправлять клиента в регистрационные поля: выбор может сразу создать посещение. Не запускать создание, редактирование, удаление, оплаты, смену статусов, отправку сообщений, отметки прочтения, блокировку экрана и сохранение настроек. Разрешены безопасная навигация и просмотр меню без выполнения операций. API, пароли, коды, cookies и токены не использовать и не сохранять. В документации фиксировать структуру и смысл, без реальных ФИО, телефонов, идентификаторов и финансовых записей. В прототип переносить только вымышленные примеры. Инвентаризация: `docs/references/astron-dev-inventory.md`; UX-рекомендации: `docs/design/ux-review.md`.

Источник: https://system.astron.club/.

По прямому требованию пользователя в старой системе разрешено **только читать и смотреть**. Нельзя менять, добавлять или удалять данные, регистрировать посещения, вводить номера карт для проверки/прохода, выполнять оплаты, изменять настройки и запускать команды. Можно изучать видимую страницу и открывать безопасные меню без выполнения действий.

Пользователь входит самостоятельно в браузере в реальном времени. Не запрашивать и не сохранять учётные данные, коды, cookies или токены. В заметках фиксировать структуру, названия полей и бизнес-смысл, без реальных данных клиентов, карт и финансовых записей.
