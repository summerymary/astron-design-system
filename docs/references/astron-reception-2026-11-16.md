# Ресепшен: источник и границы переноса

Источник: https://system.astron.club/ (вход выполнен пользователем). Просмотр 16 ноября 2026: только навигация, чтение страниц и безопасное открытие форм. Оплаты, выдача, списания, поиск карт, сохранение, печать и обращения к API источника не выполнялись. Реальные строки клиентов, сотрудников, заказов и суммы не сохранялись.

## Подарочные карты

`index.php?do=giftcard`: каталог, поиск по номеру, номер/комментарий/создание/автор/остаток, переход к списанию. Отдельные пути: `mode=sell` — продажа; `mode=add` — выдача без оплаты; `mode=online` — очередь онлайн-заказов.

Продажа: номер, номинал 1500 / 3000 / 10000 / 15000 / 20000 или произвольная сумма, комментарий, печать чека, суммы наличными и картой. Выдача без оплаты: номер, номинал, владелец по клиентской карте (обязательно), покупатель (необязательно), комментарий. Онлайн-заказы: номер, номинал, покупатель, получатель, способ получения, комментарий, выданная карта; действие выдачи. В прототипе только вымышленные оплаченные заказы; повторной оплаты при выдаче нет.

## Абонемент клиента

Основание — приложенный пользователем снимок окна истории: покупка, активация, окончание, посещения (дата, вид, клуб), действия «Заморозить», «Списать», «Договор», «Распечатать», «Переоформить». Сами действия в источнике не запускались. Прототип моделирует изменения остатка/доступа и историю, не реальные возвраты или юридические документы. Договор — обозначенный образец состава; нужен утверждённый шаблон клуба. Лимит заморозки 90 дней — настройка демо, не подтверждённое правило источника. Разморозка ручная; срок продлевается по фактическим дням.

## Расписание и персональные тренировки

Снимок пользователя: строки точного времени начала, столбцы залов, название/тренер/места, цвет интенсивности; есть брони уборки. Новый дневной вид администратора использует такую хронологическую матрицу, без пустых часов. Время окончания указано явно: высота строки не изображает длительность. Неделя и тепловая карта руководителей сохраняют непрерывную временную шкалу.

`index.php?do=personals`: перечень клиентов, плановые занятия, тренер. В прототипе адаптировано под запрос: список тренеров, их закреплённые клиенты, независимый фильтр просматриваемого клуба и запись. Категории и цены демонстрационные. Администратор управляет записью/резервом/присутствием, не создаёт, не переносит, не отменяет и не удаляет тренировки.

## Дополнения по прямому запросу пользователя

Восстановление клиентской карты — 100 ₽; после оплаты номер заменяется, история/счёт/абонементы сохраняются. Обычное исправление номера доступно в редактировании. Товары ресепшена оплачиваются без клиента; бар изолирован. Персонал администратора — контакты без изменений. График смен доступен администратору для просмотра и фитнес-директору для управления. Касса отделена внизу меню. Абонементы и продажа услуг не показываются отдельными пунктами администратора; продажа доступна из карточки/регистрации.
