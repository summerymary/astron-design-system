# Быстрый поиск клиента

В рабочей шапке администратора одно поле ищет по номеру карты, ФИО и телефону. Надпись поля — «Карта, ФИО или телефон». Это поиск по вымышленным данным в памяти, без запросов в старую систему.

- Можно вводить части ФИО в любом порядке, без учёта регистра; «ё» и «е» равнозначны.
- Телефон распознаётся со скобками, пробелами и дефисами; начальные +7 и 8 равнозначны. По части номера могут находиться несколько клиентов.
- Точный номер карты имеет приоритет перед совпадением с частью телефона. Поддерживается начало номера карты.
- В списке видны ФИО, телефон и карта, чтобы отличить однофамильцев. Внутренний ID клиента не показывается.
- Enter при единственном совпадении или точной карте открывает карточку. При нескольких совпадениях нужен выбор — мышью, касанием либо стрелками и Enter. Escape закрывает список. Кнопка с крестиком очищает поле.
- Результаты прокручиваются, активный пункт при выборе стрелками остаётся виден. Пустой результат объясняет, как уточнить запрос.
- Поиск и открытие карточки не регистрируют посещение и не меняют клиента. Посещение оформляется отдельным действием.

Номер карты остаётся в журнале в своей колонке. Под именем в строке посетителя больше нет подписи «Клиент #…». Высота десктопной строки — 40 px.

Компонент: `src/components/ClientSearch.tsx`. Чистая функция поиска и общий расчёт демо-карты: `src/lib/member-search.ts`. Поле `Member.fullName` необязательно; при его отсутствии используется `name`. Отчества в примерах вымышлены. Добавленные через форму клиенты участвуют в поиске из текущего состояния React.

`pnpm test:search` проверяет ФИО, ё/е, формат телефона и +7/8, точные и неполные карты, несколько совпадений, отсутствие результатов и неизменность демоданных. Проверка запускается в GitHub Actions перед сборкой.
