# Выпадающие списки

Единый Select используется в фильтрах, формах, расписании, продаже, переключателях ролей/состояний и дизайн-системе. Закрытое поле сохраняет подпись и выбранный вариант; полное название доступно в подсказке, если оно длиннее поля.

- Белая панель, мягкое бордовое выделение, галочка у выбранного значения. Только название и цвет вместе не заменяют галочку.
- Пункты от 44 px; текст открытого списка 16 px. Длинные названия переносятся.
- Более семи вариантов — поле поиска. Поиск не различает регистр и ё/е. Нулевой результат объясняется словами.
- Стрелки перемещают активный пункт, Enter/пробел подтверждают. Home/End и Page Up/Down помогают длинным спискам. Escape закрывает без изменения; Tab переводит к следующему полю. Выключенные варианты пропускаются.
- Список появляется поверх ограничивающих контейнеров. Расположение сверху/снизу зависит от свободного места; учитывается изменение визуальной области телефона. Внутри прокручиваются варианты, а не вся форма.
- Нативный скрытый select обеспечивает данные формы и required-валидацию; скрытый элемент не получает фокус. Ошибка выбора показана под полем. Это одиночный выбор; множественный выбор должен проектироваться отдельно.

Реализация: `src/components/Select.tsx`, `src/components/select.css`. Новых зависимостей нет. Образец и простое объяснение находятся в разделе «Кнопки и поля» и правилах рабочих экранов дизайн-системы.
