# Блокировка экрана администратора

Кнопка с замком в правой части рабочей шапки доступна администратору на всех страницах, в том числе на телефоне. Название доступно программе чтения экрана и в подсказке при наведении. Область нажатия — 44 × 44 px.

Блокировка закрывает весь прототип непрозрачным экраном, делает фон недоступным для мыши, клавиатуры и программ чтения экрана, в том числе плавающие быстрые переходы. Открытая страница, вкладка и данные в памяти не сбрасываются. Escape и нажатие вне формы не снимают блокировку. Состояние блокировки сохраняется при обновлении вкладки; данные самого прототипа после обновления, как и прежде, восстанавливаются из демопримеров.

Разблокировка в текущем прототипе — по явно указанному демонстрационному PIN `1234`. Неверный код оставляет экран закрытым и показывает ошибку; ввод ограничен четырьмя цифрами. PIN сотрудника из реальной системы не запрашивается и не сохраняется. Это демонстрация интерфейса, не реальная авторизация и не защита данных: для рабочего продукта проверка пользователя и управление сессией должны выполняться сервером.

Проверены неверный и верный PIN, Escape, Enter, возвращение к выбранной вкладке, обновление заблокированной страницы и экран 390 px. Исходные системы и их API не используются. Реализация: `src/components/ScreenLock.tsx`, `src/components/screen-lock.css`, `AdminHeader` и общая оболочка `App`.
