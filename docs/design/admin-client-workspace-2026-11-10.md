# Рабочее место администратора — 10 ноября 2026

Последнее решение пользователя заменяет прежние настройки главной, карточки и прав расписания. Реальные системы и API не подключены. Все действия выполняются с вымышленными записями в памяти.

## Работа с клиентом

- Левое меню администратора открыто при первом входе, выборе роли и восстановлении роли из истории. Сворачивание меняет ширину, сохраняя координаты иконок. У управляющих раскрытые группы не меняют состояние при сворачивании; контекст клуба сохраняет высоту.
- Крупный поиск карты, ФИО или телефона — основная рабочая зона. Далее идут новый клиент, расписание и товары. Кнопка посещения из шапки удалена. Регистрация доступна из клиентской карточки и каталога разделов. Мобильное «Продать» сохранено.
- Журнал недавних посетителей полностью убран с главной администратора. Вместо него спокойное начальное состояние для открытия клиента и короткая строка смены. Данные посещений сохраняются в карточках клиентов.
- Рабочие страницы администратора имеют максимальную ширину 1168 px с полями и выравниваются по центру; календарю разрешено до 1440 px для залов. Шапка ограничена 1120 px. На узких экранах ограничения уменьшаются до доступной ширины.

## Карточка

- Порядок вкладок: абонементы → посещения → финансы → комментарии → информация → предзапись → переписка → активность → звонки → отзывы. По умолчанию открываются абонементы.
- ФИО с отчеством показывается в карточке, базе, поиске, записи, продаже, переписке и других списках известных клиентов. Короткое имя в старых записях остаётся для совместимости связей; отображение использует `fullName`.
- У администратора телефон замаскирован без кнопки раскрытия, в том числе в форме редактирования существующего клиента, списке, поиске, регистрации и продаже. Кнопка трубки открывает демонстрацию звонка без внешнего соединения. У управляющих номер виден сразу. Это представление фронтенда, а не защита исходных данных или серверная авторизация.
- «В клубе с» убрано из заголовка; дата регистрации остаётся в информации. Наличие личного кабинета и приложения также перенесено в информацию.
- Подписи имеют размер 14 px и чуть более светлый цвет, основные значения — 18 px и тёмный текст. Шрифт не уменьшается ради размещения данных.
- «Добавить комментарий» заменяет основную кнопку «Написать». Все заметки находятся в истории с автором и временем; одна заметка на клиента закрепляется в заметной плашке. Открепление не удаляет запись. Переходы между модулями сохраняют историю и закрепление в общей памяти. Переписка остаётся отдельной вкладкой.
- У всех шести исходных клиентов есть разные вымышленные фотопортреты. При отсутствии фото остаются инициалы. Локальный атлас и запрос генерации описаны в `demo-portraits.md`.

## Расписание и присутствие

- По умолчанию день, все залы, масштаб «Весь день». Время удалено из текста плиток; оно остаётся в сетке, доступном названии, подсказке, списке и окне занятия. Мелкие окна используют прокрутку, а не микрошрифт.
- Администратор не создаёт, не переносит, не копирует и не удаляет занятия. Ограничения применяются к кнопкам, контекстному меню, свободным слотам, перетаскиванию и обработчикам сохранения. Он может отменить действующее занятие с подтверждением. Отменённое остаётся в расписании с историей, повторный щелчок не открывает создание.
- Управляющие и тренеры сохраняют свои прежние права: тренер меняет только свои персональные тренировки, управляющие работают с расписанием. Перенос требует подтверждения.
- Выбор клуба расписания у администратора отдельный от рабочего места. Можно просматривать занятия и записывать клиентов в другом клубе без изменения клуба кассы, шапки и операций смены. Пример «Парк» находится 7 ноября.
- Щелчок по занятию открывает короткое описание, тренера, время, длительность и список клиентов с фото, ФИО и картой. Поиск записи совпадает с общим поиском: карта, ФИО или телефон → выбор → отдельная кнопка «Записать клиента».
- Присутствие — отдельная обратимая отметка на занятии, как подтвердил пользователь. Она не создаёт посещение клуба и не списывает абонемент. Снятие записи требует подтверждения и снимает отметку присутствия для этого занятия. Отмена занятия сохраняет историю.
- Проверяются дубликаты, архив клиента, свободные места и пересечения его записей, в том числе в другом клубе. Количество записанных соответствует реальному списку демоданных; прежние условные счётчики без имён заменены согласованными списками.

## Проверки

Перед публикацией прошли все 11 предметных проверок, TypeScript, production build и `git diff --check`. В браузере проверены 10 ролей в обоих оформлениях: координаты основных иконок сохраняются при сворачивании. На ширинах 1280, 390 и 320 px нет горизонтального переполнения. Проверены поиск, маскировка телефона и форма администратора, открытый телефон управляющего, демозвонок, история и смена закреплённого комментария. В расписании проверены запись, присутствие, снятие с подтверждением, Escape вложенного окна, отмена и права контекстного меню. Выбор «Парк» и запись на 7 ноября не меняют рабочее место «Центральный». Тренер сохраняет форму своей ПТ. Ошибок консоли на проверенных страницах нет.

TypeScript, production build и предметные проверки дополняются проверкой прав администратора, вместимости, дубликатов, пересечения клубов, присутствия и снятия записи. В браузере проверяются обе темы, координаты иконок ролей, поиск, карточка, история/закрепление, телефон и демозвонок, запись/снятие/отмена, независимый клуб и телефонная компоновка. Сохранение черновиков между модулями (F2) не добавляется. Commit/push разрешён пользователем только для этого набора.
