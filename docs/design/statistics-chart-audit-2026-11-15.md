# Сверка диаграмм с источником — 15 ноября 2026

Повторно открыты все 48 страниц [каталога статистики](https://system.astron.club/index.php?do=statmodule) после входа пользователем. Только просмотр и навигация с ожиданием медленных страниц; формы, выгрузки, печать, аудио и операции не запускались. Сохранены только структура и подписи, без реальных записей, сумм, контактов и изображений результатов: [структурный журнал](../references/astron-statistics-charts-2026-11-15.json).

Числа прототипа вымышлены и не должны совпадать с рабочей базой. Сохраняются вопрос, разрезы и единицы диаграммы. Видимый интерфейс не подтверждает серверную формулу. Изменения локальные: новой просьбы commit/push нет.

Прежняя реализация автоматически выбирала первую таблицу и ключ `amount` или `count`. Так исчезали вторые диаграммы и рейтинги со ссылками, смешивались разрезы, пропадали среднее и состав часов. Вместо неё введён явный контракт `src/lib/statistics-charts.ts` и общий `ReportChart`.

## Соответствие и решения

| Отчёт | Источник | Прототип / обоснование |
| --- | --- | --- |
| Уникальные посетители | Круг по числу клубов, посещённых одним человеком | Полосы **числа клубов у клиента**, а не рейтинг клубов. Каждый клиент один раз. Близкие доли проще сравнить по общей шкале; клубные таблицы сохранены. |
| Рейтинг клиентов / визитов | Горизонтальные полосы суммы / числа визитов | Сохранены оба показателя. Восстановлены графики строк, связанных с карточкой клиента. |
| Посещения по параметрам | Шесть кругов: клубы, направление, пол, возраст, популярность групповых программ, тип карты; названия карт отдельной таблицей | Семь явных диаграмм и таблиц. Круги заменены полосами с полными названиями. Пол — уникальные клиенты, остальные распределения — посещения. |
| Возраст в параметрах | Интервалы до 18, 18–23, 24–29, 30–35, 36–41, 42–47, 48–54, 55–60, 61–66, 67–72, 73–78, 79+ | Те же границы вместо прежних крупных групп; возраст на конец периода. Неизвестный возраст отдельно. |
| Популярность программ внутри параметров | Сводные направления с вложенными программами; круг направлений смешивает интенсивность и вид спорта | Полосы конкретных **названий программ** дают точный ответ, какое занятие посещали. Это осознанное изменение уровня группировки. Программа определяется только квитанцией визита и занятием. Нет точной связи — «Программа не определена», без догадки по текущей предзаписи. |
| Типы и названия карт внутри параметров | Семейства отдельно от конкретных тарифов | Разделены. Типы — актуальный справочник прототипа, названия — сохранённое имя списанной карты. Старые семейства тарифов источника не выдумываются; неизвестный тип отдельно. |
| Посещения по месяцам | Линии **по дням**: всего + клубы, дневные таблицы | Дневной шаг, итог и отдельные клубы восстановлены. Дополнительная месячная таблица сохранена. Для дневного графика максимум 366 дней. |
| Источники новых клиентов | Горизонтальные полосы количества | Сохранены источник, количество и вид. |
| Половозрастная структура посетителей | Форма «только уникальные»/ПТ/набор клубов; таблица возраст × мужчины/женщины. При исходных параметрах клубы не выбраны, график не отрисован | Совместные серии по точному возрасту, визиты/уникальные, направление и клуб. Вид заполненной диаграммы источника не подтверждён. Группированные полосы выбраны для прямого сравнения. Неизвестные сведения не теряются. Произвольный набор клубов пока заменён одним клубом или всей сетью. |
| Рейтинг ПТ | Полосы количества тренировок | Количество сохранено, не подменяется часами/выручкой. СПТ — неподтверждённый термин, отдельный вид в демо не выдуман. |
| Рабочие часы | Сложенные полосы ПТ + ГП + дежурства | Три подписанные полосы на общей шкале проще сравнивать по каждому виду. Итог в таблице. Флаги ПТ/ГП/ДЧ применяются до графика. |
| Рейтинг групповых | Полосы процента заполняемости | Сохранены процент и полосы, опора 100%. В демо записанные места / вместимость, а не неподтверждённое среднее процентов источника; это указано в методике. |
| Продление | Круг продлил / не продлил | Полосы результата, незавершённое окно отдельно и не считается отказом. Процент только по завершённым окнам. Демо-окно настраивается: источник точно его не объясняет. |
| Летнее продление | Отдельные круги по годам | Отдельные диаграммы годов выбранного периода; окно три календарных месяца. Незавершённые окна отдельно. |
| После гостевого | Круг купил / не купил | Полосы «Купил абонемент» / «Не купил» / «Окно ещё открыто». Ошибочный текст каталога про летнюю карту не переносится. |
| Пол/возраст покупателей | Возрастная пирамида суммы; две таблицы суммы и среднего чека | Две диаграммы по точному возрасту и полу: **сумма** и **средний чек**. Положительные значения без искусственного минуса одной серии. Оба показателя не смешиваются; только ПТ отдельным флагом. Нет покупок — средний чек «—». |
| Выручка по месяцам | Столбцы + горизонтальное среднее | Вид сохранён. Среднее в демо = сумма сохранённых продаж / число месяцев периода, включая нулевые; неполные месяцы не экстраполируются. Формула источника не подтверждена, это определение видно под графиком. |
| Выручка по абонементам | Две горизонтальные диаграммы: сумма и количество | Обе восстановлены отдельно с единицами. |
| Групповые занятия и цены | Таблица дохода количественных/безлимитов, средней цены и общего дохода; графический контейнер без читаемого содержания | Таблица основная. Автографик первых 12 занятий убран: он терял дату и смешивал повторяющиеся названия. Вид заполненного графика источника не подтверждён. |

## Остальные страницы и ограничения

В «Статистике продаж» добавлены две явные диаграммы суммы и количества — для сравнения уже существующей таблицы. «Сегменты базы» сравниваются полосами числа клиентов, «Частота по безлимитам» — упорядоченными диапазонами частоты. В исходных состояниях этих страниц графики не наблюдались: это обоснованные дополнения, а не копии источника.

Остальные отчёты используют таблицы/показатели без принудительного графика по первой числовой колонке. Время жизни, LTV, финансовый результат и обязательства имеют разные смыслы и единицы. `fail_finance_report` снова показал пустую область: это не нулевое число ошибок. Все формулы, которые нельзя подтвердить по интерфейсу, остаются демонстрационными — см. [statistics.md](statistics.md).

## Единый контракт диаграмм

- Значения серий берутся из тех же блоков, что таблица. День московский; деньги в копейках до форматирования. Неизвестное значение «—», не ноль.
- Количественная шкала начинается с нуля. Серии одной диаграммы имеют общий максимум. В заполняемости 100% опорная граница; нули не растягиваются.
- Подпись и точное значение доступны без наведения/цвета. У временного графика текстовое описание и таблица. Линии различаются штрихом и подписанной легендой.
- После 12 категорий есть кнопка полного списка, ничего не теряется. Временные ряды не обрезаются до 12 точек и идут по календарю.
- Токены четырёх тем общие. Фокус и кнопки стандартные; временной график прокручивается внутри своего блока, доступного с клавиатуры.
- API клуба не вызываются. Полные серверные формулы, историю и права повторяет разработчик при внедрении.
