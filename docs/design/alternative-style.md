# Темы Астрон, Графит и Тёмная

Контраст и Тёмная теперь отдельные темы. Контраст восстановлен по светлому варианту: фон #F4F3F0, белые панели, палитра Астрона, рамки панелей #B8AEA6 и полей #746C63, визуальная толщина 2 px. Его URL ?style=contrast и внутренний id contrast. Тёмная сохраняет палитру и усиленные рамки опубликованной версии: ?style=vivid, id dark. Прежние ссылки ?style=vivid продолжают открывать Тёмную. Обе темы сохраняют геометрию, данные и страницу; цвет бренда не подменяет их фиксированные палитры. Нативные поля используют light для Контраста и dark для Тёмной.


В верхней панели один список тем одного приложения. Маршруты, данные, сетка, размеры, роли и поведение общие. Исходные Астрон и Графит сохранены.

Тёмная тема: фон #202020, тёмно-серые панели #2A2A2A, дополнительные поверхности #242424 / #343434. Основные данные белые #FFFFFF, текст #EEEEEE, подписи #BFBFBF. Бордовые кнопки #963646 с белым текстом; hover #A94153, pressed #7E2938. Рамки панелей ярче #9B7A84, полей #C38B9A, основных кнопок #EDABBA. Рамка 1 px вместе с внутренней линией 2 px даёт визуальные 3 px без изменения размеров. Акцент #FFB4C4, выбранный пункт обведён внутренней линией 3 px, активная вкладка подчёркнута на 4 px. Нативные поля тёмные (color-scheme:dark), логотип на тёмном белый. Цвета статусов и категорий сохраняют смысл. Геометрия, маршруты и поведение общие с Астроном.
