# Контрастная палитра «Астрон»

6 ноября 2026 года по просьбе пользователя о более стильной и контрастной теме предложен глубокий бордовый с графитовым текстом, белыми карточками и нейтральным светло-серым фоном. Он заменяет прежнее сочетание #8A332C с кремовыми поверхностями. Серо-зелёные подписи #606A5C сохранены. Значения — `src/styles/tokens.css` и `ASTRON_TOKENS` в `src/lib/theme.ts`; тест проверяет совпадение. Каталог получает активную тему из контекста. Другие темы: [адаптивная палитра](adaptive-palette.md).

| Назначение | Цвет | Использование |

| Фон / поверхность | `#F4F5F7` / `#FFFFFF` | Рабочая область и карточки |
| Разделитель | `#DCE1E7` | Структура таблиц и карточек |

Бордовый выделяет действия и выбранный контекст. Текст таблиц остаётся нейтральным. Успех и ошибка не используют брендовый акцент. Статусы сопровождаются подписями, выбранные вкладки — линией, фокус клавиатуры — контуром. Светлые разделители не заменяют контрастные границы полей.

## Плотность таблиц

В списке клиентов и журнале посетителей высота обычной строки — 40 px. После первого уплотнения с примерно 70 до 48 px пользователь попросил сократить строки ещё. Общие токены: `--table-record-row-height`, `--table-record-padding-y`, `--table-record-avatar-size`. Вертикальные отступы — 3 px, аватары — 24 px. Размеры текста сохранены; уменьшен свободный промежуток вокруг содержимого. Табличная высота допускает рост при увеличении текста. На телефоне сохраняются отдельные карточки и удобные области нажатия.

## Контраст

Проверка палитры ориентируется на [WCAG 2.2: Contrast Minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) — 4,5:1 для обычного текста и 3:1 для крупного — и [Non-text Contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html) — 3:1 для значимых границ и индикаторов состояния.

Измеренные сочетания:

| Сочетание | Контраст |
| --- | --- |
| Белый текст / основной акцент | 9,70:1 |
| Белый текст / наведение | 12,02:1 |
| Белый текст / нажатие | 14,50:1 |
| Бордовый текст / мягкий акцент | 8,44:1 |
| Вторичный текст / белая поверхность | 5,66:1 |
| Вторичный текст / светло-серый фон | 5,18:1 |
| Вторичный текст / мягкий акцент | 4,93:1 |
| Граница поля / белая поверхность | 3,65:1 |
| Успех / его фон | 6,24:1 |
| Внимание / его фон | 6,01:1 |
| Ошибка / её фон | 5,93:1 |
| Информация / её фон | 5,90:1 |
| Заморозка / её фон | 5,75:1 |

Кроме проверки пар выполнена проверка вычисленных цветов текста на отрисованных страницах: карточка клиента, ресепшен, основы/компоненты/паттерны дизайн-системы, личный кабинет. На ширине 390 px проверены личный кабинет, ресепшен и карточка клиента. Эта проверка относится к палитре и не заменяет полный аудит доступности приложения.

3 ноября 2026 года по выбору пользователя вторичный текст изменён с `#71635C` на `#606A5C`. Дополнительные подписи используют тот же оттенок через `--color-subtle`; цвета смысловых статусов не меняются. После замены проверены вычисленные цвета текста на ресепшене и в стайлгайде на десктопе и телефоне.

После уточнения палитры проверены вычисленные цвета текста в компактных таблицах. При дальнейшем уплотнении проверять фактическую высоту строк в браузере и переход из строки в карточку клиента. В текущем макете проверено: строки обоих списков — 40 px на ширине 1440 px, имя — 12 px, email — 10 px; переход в карточку работает. Мобильные строки списка клиентов сохраняют высоту 64 px.

## Иконка браузера

Фавиконка использует основной бордовый `#7A263A` с белой буквой «А». Отдельный фирменный компактный знак «Астрона» пока не предоставлен. В `index.html` тот же цвет задан в `theme-color`; версия URL иконки обновлена для сброса старого кэша браузера. Правила полного логотипа и добавления других клубов: `docs/design/club-branding.md`.
